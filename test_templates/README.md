# CONTOH: Test Cases untuk Toko Reparasi HP

Folder ini berisi template test cases untuk berbagai jenis bisnis.
Pilih yang paling sesuai dengan bisnis Anda, copy, dan customize!

## 📁 Available Templates

### 1. Phone Repair Shop (Toko Reparasi HP)
- File: `test_cases.phone_repair.yaml`
- Untuk: Workshop reparasi, servis HP, ganti layar, dll
- Test focus: Jenis perbaikan, harga servis, durasi perbaikan

### 2. Phone Store (Toko Jual HP)
- File: `test_cases.phone_store.yaml`
- Untuk: Toko elektronik, toko HP, retail phone
- Test focus: Daftar produk, harga, ketersediaan stock

### 3. E-Commerce (Toko Online)
- File: `test_cases.ecommerce.yaml`
- Untuk: Toko online umum, fashion, barang elektronik
- Test focus: Produk, harga, ongkir, cara pembayaran

### 4. Restaurant/Cafe
- File: `test_cases.restaurant.yaml`
- Untuk: Restoran, cafe, warung makan
- Test focus: Menu, harga, jam buka, metode pemesanan

## 🚀 Cara Pakai

1. **Pilih template** yang paling sesuai dengan bisnis Anda
2. **Copy ke file utama**: `cp test_cases.phone_repair.yaml ../test_cases.yaml`
3. **Edit dan customize** sesuai data bisnis Anda
4. **Jalankan tests**: `python ../demo_test_runner.py`

## 💡 Tips

- Pastikan informasi bisnis di `business_info` akurat
- Sesuaikan `pertanyaan` dengan bahasa yang sering ditanya customer
- Adjust `jawaban_diharapkan_pattern` sesuai style bot Anda
- Test secara regular saat ada update fitur
